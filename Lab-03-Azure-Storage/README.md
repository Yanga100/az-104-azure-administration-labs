# Lab 03 – Azure Storage

## Objective

Create and configure an Azure Storage Account and demonstrate basic Azure Blob Storage operations.

## Environment

- Microsoft Azure
- Resource Group: AZ104-Lab-RG
- Region: South Africa North
- Storage Account: az104labstorage03
- Performance: Standard
- Replication: LRS
- Account Kind: StorageV2
- Access Tier: Hot

## Tasks

- Create an Azure Storage Account
- Configure storage redundancy
- Configure data protection
- Configure storage security
- Apply the Environment tag
- Create a Blob container
- Upload a blob
- Verify blob properties
